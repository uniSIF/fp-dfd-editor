# UIデザイン書: FP法見積もり用 DFD GUIエディタ

- 版: 1.0（2026-11-02）
- 入力: [requirements.md](./requirements.md)、[design.md](./design.md)
- モック: [ui/mock/index.html](./ui/mock/index.html)（ブラウザで直接開く。外部依存なし）
- 対象: ライトテーマのみ。MUI を前提とし、各トークンを `createTheme` に落とし込める形で定義する。

---

## 1. デザイン原則

| 原則 | 内容 |
|---|---|
| 情報密度を優先する | 見積もり担当者は表とキャンバスを行き来しながら数十〜数百の機能を扱う。余白より一覧性を取り、本文 13px、行高 32px のコンパクト密度にする。 |
| 計上されるものだけが色を持つ | FPに計上されるファンクション（EI/EO/EQ/ILF/EIF）には種別色のバッジを付け、計上されない要素（非計上プロセス、外部エンティティ、参照配置）は無彩色・淡色・破線で描く。画面のどこを見ても「数えられているか」が色で分かる。 |
| 警告は色と形で二重に示す | 警告色の枠線に加えて必ず三角アイコンと文言を併記し、色覚特性に依存しない。 |
| キーボードで完結する | 主要操作にショートカットを割り当て、フォーカスリングを常に可視化する。 |
| 装飾しない | 影・グラデーション・アニメーションは状態変化（選択、ダイアログ開閉、Snackbar）を示す場合だけに使う。 |

記憶に残る要素は DFD キャンバス上の Yourdon/DeMarco 記法のノードとその種別バッジに限定し、周囲のクローム（ツールバー、ツリー、表）は静かに保つ。

### 3.2 ファンクション種別色

バッジ（`--badge-*`）は白文字を載せるため、すべて白に対して 4.5:1 以上のコントラストを持つ。

| トークン | 値 | 種別 | 図形 |
|---|---|---|---|
| `--badge-ei` | `#2457A5` | EI 外部入力 | 円（実線） |
| `--badge-eo` | `#2E7D4F` | EO 外部出力 | 円（実線） |
| `--badge-eq` | `#B4690E` | EQ 外部照会 | 円（実線） |
| `--badge-ilf` | `#6A3FB5` | ILF 内部論理ファイル | 平行線（実線） |
| `--badge-eif` | `#5B6470` | EIF 外部インタフェースファイル | 平行線（実線） |
| （なし） | — | 非計上プロセス | 円（破線、背景 `#F1F3F5`） |
| （なし） | — | 外部エンティティ | 四角（実線、太め 1.5px） |

EI と primary が同じ青なのは意図的である。「入力」が最も多く描かれるため、画面全体の青の量を抑え、EO/EQ/ILF が相対的に目立つ。

## 4. コンポーネント仕様

### 4.1 Toolbar

- 左から: アプリ名（12px、secondary）、プロジェクト名（13px、600）、未保存ドット（primary 色 6px、未保存時のみ）。
- 中央: アイコンボタン群をグループごとに 1px 縦罫線で区切る。「新規・開く・保存」「Undo・Redo」「自動整列」「CSV 出力・SVG 出力」「設定」。
- アイコンボタンは 32×32、ホバーで `--color-primary-soft` 背景。ツールチップにショートカットを併記（例: 「保存 ⌘S」）。
- Undo/Redo は履歴がないとき disabled。自動整列・SVG 出力は DFD タブ以外では disabled。

### 4.2 FeatureTree

- 行高 32px。階層ごとに 16px インデント。アイコンで階層を区別: ソフトウェア＝四角アイコン、大分類・中分類＝フォルダ、機能＝円アイコン（DFD を持つことを示す）。
- 選択行: 背景 `--color-primary-soft`、左端 3px の primary バー。ホバー: 背景 `#F3F5F8`。
- 機能行の右端に警告件数チップ（`--color-warning-soft` 背景、warning 文字、11px）。
- 行末ホバーで「＋」「⋯」が現れる。「＋」は子要素の追加、「⋯」は改名・削除・並べ替えメニュー。
- ツリー上部に「ソフトウェアを追加」ボタンと検索欄（機能名のフィルタ）。

### 4.3 パンくず・Tabs

- パンくず: 「ソフトウェア / 大分類 / 中分類 / 機能」。機能名のみ `--color-text`、それ以外は secondary。クリックでツリーの該当行にスクロール。幅が足りないときは先頭側から省略記号で切り詰め、機能名を常に残す。
- 費用サマリー（パンくず行の右端、常時表示）: 「この機能の開発単価」と「ソフトウェア合計」の 2 項目を横に並べる。ラベル 11px secondary、金額 14px 600 `tabular-nums`、単位「円」は 12px。項目間は 1px 縦罫線で区切り、合計側の背景を `#F7F8FA` にして区別する。タブ切替・ノード選択・スクロールの影響を受けない。機能未選択時は合計のみ。ホバーで内訳（工数、社内／外注）をツールチップ表示。
- Tabs: 「DFD」「ファンクション表」「一覧」「台帳」。選択タブは下線 2px primary。高さ 36px。「一覧」「台帳」はソフトウェア単位の画面なので、機能未選択でも有効。

### 4.4 DfdCanvas

| 要素 | 仕様 |
|---|---|
| 背景 | `--color-canvas` にドットグリッド（16px、`#D5D9E0`、半径 1px） |
| パレット | キャンバス左上に縦並びの 5 ボタン（TF 追加 / 非計上プロセス追加 / DF 追加 / 外部エンティティ追加 / 既存を参照）。幅 36px、ホバーで右にラベルがスライド表示。ドラッグでキャンバスに落とせる |
| Controls | 左下に「＋」「−」「全体表示」「ロック」。React Flow 標準の `Controls` をトークン色で再スタイル |
| MiniMap | 右下 160×100、角丸 6px、ノードは種別色の塗り |
| システム境界 | 内部の要素（TF・非計上プロセス・ILF）を囲む角丸 12px の枠。線 2px `--color-primary`、塗りなし。左上に 12px 600 primary で「システム境界: ソフトウェア名」。外部エンティティと EIF は外側。選択・クリックの対象にせず、背面のキャンバスへクリックを通す。ノードのドラッグに追従する |
| 凡例 | 右上、幅 268px、角丸 6px。見出し「凡例」と折りたたみボタン。種別バッジ・種別名・件数を 5 行、区切り線の下に「合計 N 件」「未調整FP N」。参照配置があれば「参照（他機能所有・計上外） N 件」、未配置があれば warning 色で「うち DFD 未配置 N 件」。折りたたみ時は 1 行で合計と未調整 FP のみ。全体表示は上側に余白を取り、ノードが凡例・パレットに隠れないようにする |
| 空状態 | 中央に「ノードがありません」＋「パレットから追加するか、ファンクション表で追加してください」＋ TF 追加ボタン |

### 4.5 ノード

寸法は design.md 6.2 の `GEOMETRY` と一致させる（プロセス直径 88、データストア 180×44、外部エンティティ 140×60）。

| 状態 | 表現 |
|---|---|
| 通常 | 輪郭 `--color-border-strong` 1.5px、塗り白。名称 13px 中央揃え、2 行まで |
| ホバー | 輪郭を `--color-text` に |
| 選択 | 輪郭 primary 2px ＋ 外側 4px の `--color-primary-soft` 光彩。ハンドル（4 方向、6px 円）を表示 |
| 参照（他機能所有の DF、外部エンティティ） | 名称は通常色のまま、下に「所有: ○○」を 11px secondary で補記。バッジは種別色のまま（種別は変わらないため） |
| 警告 | 輪郭 `--color-warning` 2px、左上に三角アイコン。ホバーで警告文のツールチップ |
| 未接続 | 輪郭を破線にせず、警告と同じ扱い（薄い warning 枠 1.5px） |
| 非計上プロセス | 輪郭破線 `6 4`、塗り `#F1F3F5`、名称 secondary |
| 外部エンティティの複数配置 | 同じ外部エンティティが DFD に複数あるとき、左上の角に 12px の斜線（`--color-text`、1.5px）を描く。プロパティパネルの「接続」欄の下に説明文と「入力側と出力側に分ける」（入力と出力の両方があるときのみ有効）、「もう 1 つ配置」を置く |
| 説明あり | 右上に 12px のメモアイコン（secondary 色）。ホバーで最大幅 320px のツールチップに説明全文を表示。図形内には描画しない |

バッジ: 高さ 16px、角丸 3px、白文字 11px 600、横 padding 5px。プロセスでは円の上端に重ね、データストアでは左端の平行線の間に置く。displayNo（`TF-001`）は 11px secondary で名称の下に表示。

### 4.6 エッジ

- 直線（design.md 9.2 と同じ）。線 `--color-border-strong` 1.5px、終端に塗りつぶし矢印 8px。
- ホバー: `--color-text`。選択: primary 2px、中点にラベル編集の小さな入力が出る。
- ラベル: 12px、白背景 padding 2px 4px、線の中点に配置。
- 接続ドラッグ中: 接続可能なノードは輪郭が primary に、不可のノードは変化なし。ドロップで拒否された場合は Snackbar（4.10）。

### 4.7 PropertyPanel

- 見出し行: 種別バッジ ＋ displayNo ＋ 「機能のプロパティ」への切替リンク。
- 機能のプロパティ表示中に DFD 上の選択（ノード、複数選択、データフロー）が残っている場合は、見出し右に「◀ 選択中の要素名」の戻るリンクを出し、選択中の要素のプロパティへ戻れるようにする。選択がなければ表示しない。
- フィールドは「ラベル（12px secondary、上）＋ 入力（28px）」の縦積み。ラベル幅を揃えた 2 列は使わない（幅 320px では折り返すため）。
- セクション: 「警告」（該当時のみ。見落とさないよう先頭に置く）、「基本」（名称、種別、複雑度、FP）、「説明」（複数行。プレースホルダ「このファンクションを配置した理由や補足」。入力に応じて伸び、最大 6 行でスクロール）、「所有／所属」（機能名。DF は変更可、TF は読み取り専用）、「接続」（入力元・出力先のノード名リスト。クリックで選択移動）、「機能の計算結果」（2 列の定義リスト）。
- 機能のプロパティ表示時: 「基本」（名称、開発区分、外注業者）、「説明」（複数行。プレースホルダ「この機能の概要」）、「システム特性」（C1〜C14 を 2 列 7 行のセレクトで表示、下に「既定値で上書き」）、「計算結果」（未調整FP〜開発単価を 2 列の定義リストで表示）。

### 4.8 DataGrid（ファンクション表・一覧・台帳）

- density compact: 行高 32px、ヘッダ 36px、セル padding 0 8px。
- ヘッダ: 背景 `#F7F8FA`、12px 600 secondary。数値列は右揃え、`tabular-nums`。
- 編集可能セル: ホバーで右端に鉛筆アイコン。ダブルクリックまたは Enter で編集。
- 参照行（ファンクション表）: 文字色 `--color-text-disabled`、区分列に「参照」チップ、名称の後ろに「所有: ○○」。
- 操作列: 行末に「接続を追加」（リンクアイコン）、「複製」（コピーアイコン）、「削除／配置解除」（✕）を並べる。
- 配置・接続列: 未配置は「配置する」リンク、配置済みは「接続 N」（ホバーで接続先とラベルの一覧）、未接続は警告表示。
- 接続追加ダイアログ: 「向き」（この要素から出力 → ／ ← この要素へ入力）、相手の一覧（種別バッジ付き。接続ルール違反は無効化し「接続不可」、既存の接続は「接続済み」、未配置は「未配置（自動配置）」と右端に表示）、ラベル（任意）。確定ボタンは「接続を追加」。プロパティパネルの「接続」欄の下にも「＋ 接続を追加」を置く。参照行の複製は無効化し、ツールチップで理由を示す。
- 説明列: 幅 240px、1 行表示で末尾を省略記号にし、ホバーでツールチップに全文。ダブルクリックで複数行エディタ（セル内で 3 行に広がる）。未入力のセルはプレースホルダ「説明を追加」を disabled 色で表示。
- 警告行: 行頭に三角アイコン、背景 `--color-warning-soft`。
- 合計行（一覧）: グリッド下部に固定。背景 `#F7F8FA`、上罫線 2px `--color-border-strong`、600。
- 一覧は列数が多いため横スクロールし、機能名の 3 列（大分類・中分類・小分類）を左に固定する。
- 行選択: 背景 `--color-primary-soft`。ファンクション表で行を選ぶと DFD の該当ノードも選択される。

### 4.9 StatusBar

- 高さ 24px、11px、背景 `#F7F8FA`、上罫線。
- 左: 「最終保存 10:42」「バックアップ 10:51」。保存が一度もなければ「未保存」。
- 右: 未保存インジケータ（primary ドット＋「未保存の変更」）、警告件数（三角＋「警告 2」。クリックでポップオーバーに一覧、クリックで該当箇所へ移動）、自動バックアップ無効時は「自動バックアップ無効」を warning 色で表示。

### 4.10 Dialog / Snackbar

- Dialog: 幅 480px（設定は 640px）、角丸 6px、`--shadow-popover`。見出し 14px 600、本文 13px、フッタのボタンは右揃えで「キャンセル（テキスト）」「主操作（contained）」。破壊的操作は error 色の contained。
- 削除ダイアログは本文に影響範囲（件数・参照元機能名）を箇条書きで示す。
- 追加ダイアログ（TF / DF / 非計上プロセス / 外部エンティティ）には「説明（任意）」の複数行欄を所属機能の前に置く。初期 2 行、最大 6 行。
- 複製ダイアログは追加ダイアログと同じ構成で、見出しを「〜を複製」、確定ボタンを「複製して配置」にする。名称欄は「元の名称（コピー）」を全選択した状態で開き、そのまま入力すると置き換わる。
- Snackbar: 画面下中央、幅 auto（最大 560px）、背景 `--color-text`、白文字 13px。エラーは左端に 3px の error バー、情報は 4 秒で消える。

## 6. インタラクション

| 操作 | 視覚フィードバック |
|---|---|
| ノード選択 | 4.5 の選択状態。右ペインが即座に切り替わる。ファンクション表の該当行もハイライト |
| ドラッグ接続 | ハンドルから線が伸び、接続可能なノードの輪郭が primary に。不可ノードにドロップすると線が消え Snackbar「外部エンティティとデータストアは直接接続できません。プロセスを介してください。」 |
| 参照の重複配置 | Snackbar「顧客マスタ はこの DFD に配置済みです。」 |
| 削除 | Delete キーで 4.10 のダイアログ。DF/EE は「配置を解除」「実体を削除」「キャンセル」の 3 ボタン。参照中の場合「実体を削除」は disabled にし、理由を本文に示す |
| 自動整列 | 0.2 秒のトランジションでノードが移動（`prefers-reduced-motion` では即時）。直後に全体表示 |
| 保存 | Snackbar「保存しました」（success 色の左バー）。未保存ドットが消える |
| バックアップ | ステータスバーの時刻が更新されるのみ。通知しない |
| 未保存で読み込み | Dialog「保存していない変更があります」本文に最終保存時刻。「読み込む」は error 色 |

## 7. アクセシビリティ

- テキストと背景のコントラスト比 4.5:1 以上。バッジの白文字は 3.2 の色で担保する。secondary テキスト `#5B6470` は白背景で 5.6:1。
- フォーカスリングは `--focus-ring` を全要素に統一し、`:focus-visible` で表示する。
- キャンバス上のノードは Tab で順に移動でき、Enter で選択、矢印キーで 8px 移動（Shift で 1px）。
- アイコンボタンには必ず `aria-label` とツールチップを付ける。
- 警告は色・アイコン・文言の 3 つで示す。
- `prefers-reduced-motion: reduce` でトランジションを無効化する。

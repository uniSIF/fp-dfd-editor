# DFD の SVG を Excel に貼るマクロ

「SVG出力」の ▼ →「すべての DFD を一括出力（ZIP）」で出力した ZIP（FR-SVG-07）から、DFD を機能ごとのシートに貼った Excel ブックを作るマクロです。

- マクロ: `tools/excel/DfdSvgToExcel.bas`（取り込み用。Shift_JIS・CRLF）
- ソース: `tools/excel/DfdSvgToExcel.vb`（UTF-8。編集はこちらで行い、`npm run build:macro` で `.bas` を作り直す）

## 対応する Excel

Windows 版の Microsoft 365・Excel 2021・Excel 2019（SVG の図を貼れる版）。Mac 版の Excel では動きません。

## できるブック

- 「目次」シート: 大分類・中分類・機能名の一覧。機能名を押すとその機能のシートへ移動します。
- 機能ごとのシート（ツリーの順）: シート名は機能名です。A1 に「大分類 / 中分類 / 機能名」、A2 に目次へのリンク、A3 を左上にして DFD の図を貼ります。
  - 図は SVG のまま貼るので、拡大しても粗くなりません。幅が 900 ポイントを超える図は縦横比を保って縮小します。
  - Excel のシート名の制限（31 文字以内、`\ / ? * [ ] :` は使えない、同じ名前は使えない）に合わない機能名は、使えない文字を `_` にする、切り詰める、「 (2)」を付けるなどして名前を変え、最後に一覧で知らせます。

ZIP の `index.tsv`（パス・大分類・中分類・機能名の一覧）から、シートの順番と元の機能名を読みます。`index.tsv` がない場合は、フォルダ・ファイル名の順に並べ、ファイル名を機能名とします。

## 使い方

### 1. マクロを取り込む（初回だけ）

1. Excel で空のブックを開き、`Alt` + `F11` で VBA エディターを開きます。
2. 左の「プロジェクト」で「VBAProject (PERSONAL.XLSB)」を選びます。ない場合は、次の手順で作ります。
   1. Excel の「表示」→「マクロ」→「マクロの記録」を開き、「マクロの保存先」を「個人用マクロ ブック」にして「OK」を押します。
   2. すぐに「記録終了」を押します。
3. 「ファイル」→「ファイルのインポート」で `DfdSvgToExcel.bas` を選びます。「標準モジュール」に「DfdSvgToExcel」が追加されます。
4. VBA エディターを閉じます。Excel の終了時に個人用マクロ ブックの保存を確認されたら「保存」を押します。

個人用マクロ ブックに入れると、どのブックからでも実行できます。1 つのブックだけで使う場合は、そのブックに取り込み、マクロ有効ブック（.xlsm）で保存してください。

### 2. 実行する

1. `Alt` + `F8` でマクロの一覧を開き、「PERSONAL.XLSB!ImportDfdSvgs」を選んで「実行」を押します。
2. 「DFD の ZIP ファイルを選びますか？」に答えます。
   - 「はい」: アプリから出力した ZIP ファイルを選びます。マクロが一時フォルダに展開し、終わったら消します。
   - 「いいえ」: ZIP をエクスプローラーで展開したフォルダを選びます。
3. 新しいブックができ、「目次」シートが開きます。名前を付けて保存してください（マクロを含まない .xlsx で保存できます）。

## うまくいかないとき

- 「ZIP ファイルを展開できませんでした」: エクスプローラーで ZIP を右クリック →「すべて展開」で展開し、手順 2 で「いいえ」を選んで展開したフォルダを選んでください。
- 「図を貼れませんでした」: SVG の貼り付けに対応していない版の Excel です。Microsoft 365 などで実行してください。
- マクロを実行できない: 会社の設定でマクロが無効になっている場合があります。管理者に確認してください。
